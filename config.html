GitHub

Use a fine-grained token limited to this one repository with "Contents: Read and write". The token and settings are stored in this browser permanently; the encryption password is kept only while this tab is open and must be entered again after a reload or restart. The data file in GitHub is always encrypted with your encryption password; if you lose the password the file cannot be recovered.

Change encryption password

The file in GitHub is re-encrypted with the new password. The GitHub settings above (including the token) must be filled in. If you forget the current password the file cannot be recovered.

Defaults for a new salary line

These values are copied into every new line you add on the My salary page. Lines that already exist keep their own values. The five amounts below the per-person ones are in UAH.
