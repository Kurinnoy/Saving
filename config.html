GitHub

Use a fine-grained token limited to this one repository with "Contents: Read and write". The token and local setup are stored in this browser; the encryption password is kept only while this tab is open and must be entered again after a reload or restart. Savings data and setup in GitHub are encrypted with your encryption password; if you lose the password the file cannot be recovered.

Change encryption password

The file in GitHub is re-encrypted with the new password. The GitHub settings above (including the token) must be filled in. If you forget the current password the file cannot be recovered.

Family setup

Select the people to include and set the amount saved for each on every new salary line. "New salaries only" keeps a person's Include and currency as they are in the salary months you already have, so a change here only affects salaries you add afterwards. The checkboxes choose where each person appears: Salary table columns, History table columns, History details (each month's Income/Spending list on Family Savings), the Totals blocks on Family Savings, the Salary footer and History total rows and the History Total column. Unticking Include hides the person everywhere and locks their other checkboxes. Drag a row by its handle (or focus the handle and press the up or down arrow) to change the order, then save.

Other monthly defaults

These zero-valued defaults are copied into new salary lines. Existing lines keep their saved amounts. "New salaries only" keeps a row's Include, amount and currency as they are in the salary months you already have, so a change here only affects salaries you add afterwards (a month that never had the row does not get it). "Totals block" is the summary block at the top of Family Savings; "History details" adds the row to each month's Income/Spending list there; "Add to dropdown" lets you pick the row in the Who list when adding an income or spending line (lines for it change its amount like Monthly saving); Unticking Include hides the row everywhere (including the My salary Details) and locks its other checkboxes; "Salary footer" is the Total row under the My salary table and "History total" the Total row under the History table on Family Savings. Drag a row by its handle (or focus the handle and press the up or down arrow) to change the order, then save; rows stay within their own group. A % row is taken either from the Salary or from the Net salary left after the % rows above it (for 1000: 1% = 10, 5% = 50, then 10% of 940 = 94).
